# 实施计划：Harness 与 Skill 架构升级规划 (v2.0)

## 目标
全面升级 `medpatent` 的 Harness 架构与 Agent Skills，从根本上杜绝数据去重失败、技术幻觉（例如将机械专利误读为 AI 软件）、数据丢失以及报告前后的自相矛盾。

本次升级遵循 2026 AI 工程范式：**“约束即杠杆”** 以及 **“Pipeline/Reviewer 协议优于自由提示词”**。

## 用户评审项

> [!WARNING]  
> 本计划提议在 AI 工作流中增加严格的“守门”机制。这意味着 AI 生成最终报告的步骤会增加，但其准确性将得到工程级的保障。请确认这些架构约束是否符合您的预期。

## 🔴 当前核心问题根因分析

1. **专利重复 (81 变 59)**：之前的数据处理脚本缺少 **Pipeline Gate (管道关卡)** 来进行专利家族去重（例如合并同一项发明的 A1 和 B2 公开文本）。
2. **遗漏核心专利 (US20220015832A1)**：过滤逻辑属于“黑盒脚本”，缺乏 **Inversion Pattern (反转模式)**（即 AI 在输出前未主动与已知的 Baseline 基准库进行对撞校验）。
3. **分析幻觉 (机械 vs. AI)**：AI 掉入了“单次生成（One-Shot）”陷阱。在被要求总结专利时，它进行了过度泛化，在缺乏证据的情况下盲目猜测软件功能。
4. **前后矛盾**：AI 是在没有“事实记录系统（System of Record）”的情况下动态生成的报告，导致不同章节对同一专利的陈述不一致。

## 建议的架构调整

### 1. Harness 层：强制执行 "Pipeline" 与 "Inversion" 模式
我们将舍弃用于数据处理的临时脚本，转而固化为严谨的数据管道，以防止数据重复和丢失。

#### [新建] .agents/skills/patent-data-pipeline/SKILL.md
创建一个专门负责数据完整性的新 Skill。
- **步骤 1：家族去重算法**：剥离类型代码 (A1, B2)，按标准的 INPADOC 家族 ID 或严格的申请号基准进行分组。
- **步骤 2：反转校验 (基准验证)**：Agent *必须* 在输出前声明：“我已经将列表过滤至 X 件。我正在检查已知核心专利（如 US20220015832A1）是否在列表内。”如果被误删，管道立即阻断并说明原因。

### 2. Skill 层：针对 CPC 分类号强制执行 "Reviewer" 模式
为了防止 AI 将机械硬件幻觉为软件方案，我们将引入基于客观分类数据的物理约束。

#### [修改] .agents/harness/references/classification_guidelines.md
增加严格的映射规则：**“CPC 强约束”**
- *规则*：在分析任何专利前，AI 必须先检查 CPC 代码。
- *约束*：如果专利属于纯 `A61B17` (手术器械)，除非在权利要求原文中能提取出包含神经网络或图像处理单元的**直接引文**，否则**严禁** AI 将其标记为“深度学习”、“自动图像识别”或“软件追踪”。

#### [修改] .agents/skills/patent-claims-analyzer/SKILL.md
更新 Skill 逻辑，要求执行多步清单：
1. 提取 CPC。
2. 设定“技术领域假设”（例如基于 CPC 判断是机械还是数字方案）。
3. 提取权利要求。
4. 如果权利要求与 CPC 假设冲突，记录特定的警告并请求人工介入。

### 3. 执行层：上下文持久化与防矛盾机制
为了防止报告自相矛盾，我们将停止让 LLM 直接撰写整篇报告。

#### [修改] .agents/skills/patent-application-creator/SKILL.md (或相关报告生成器)
实现 **Generator Pattern (生成器模式)**：
- **阶段 1**：Agent 遍历所有 59 件去重后的专利。
- **阶段 2**：为每件专利生成严格的 JSON Schema (`feature_list.json`)，包含精确映射的属性（如 `is_optical`、`is_software`、`source_claim`）。
- **阶段 3**：最终报告生成提示词 *只读* 填充好的 JSON，完全禁止其进行不受限的“即兴发挥”。

### 4. Harness 知识库：事实记录系统
#### [修改] .agents/harness/FAULT_DIARY.md
记录本次故障模式，确保 Harness 维护者永不再犯。
- **增加故障**：“张冠李戴型幻觉（如 US9283050B2）。AI 混淆了弯套管机械系统与自动视觉追踪系统。”
- **增加缓解措施**：“开启 CPC 交叉评审 Skill。强制引用原文。拒绝任何缺乏 JSON 事实支撑的功能声明。”

## 校验计划
1. **开发** 更新后的 Skill 定义与准则文件。
2. **执行** 新的 `patent-data-pipeline`，验证总数是否精准从 81 降至 59 族，并显式确认 `US20220015832A1` 的存在。
3. **测试** 针对有争议专利（`US9283050B2`）运行 `patent-claims-analyzer`。验证 AI 是否能正确识别其为纯机械/控制专利，不再幻觉视觉追踪功能。
