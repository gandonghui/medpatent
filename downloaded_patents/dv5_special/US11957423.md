## Abstract
A robotic surgery system comprising a plurality of motorized robotic arms of a surgical robot configured to perform surgical steps on a patient and a display system for multi-user control of the robot of a surgical procedure. The display system includes a console including left and right hand-operated input devices physically manipulatable by a first user and a viewer configured to display one or more instruments carried by the plurality of robotic arms to the second user. The display system also includes a second user device configured to display a graphical user interface having patient data of the patient and an authorization input for a second user to be authorized to switch control of at least one of the robotic arms from the first user to the second user.
